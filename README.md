# My AI Challenge Tracker

A simple, 11-week AI learning tracker. Check off each week and keep notes as you go. Progress is saved in your browser's local storage on this device; clearing site data will remove it.

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server. No build step or dependencies are required.

## Publish with GitHub Pages

In the repository's **Settings → Pages**, choose **Deploy from a branch**, select the branch containing these files and the **/(root)** folder, then save. GitHub Pages will publish the site at the URL shown in the Pages settings.
